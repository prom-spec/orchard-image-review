# דף בחירת תמונות

הדף `image-choices.html` מציג את התמונות שכבר נשמרו ואת המועמדים שיוספו ל־`candidates.csv`.

להצגה מקומית:

```bash
cd /home/nimrod/.openclaw/workspace/orchard-calendar
python3 -m http.server 8787
```

ואז פותחים בדפדפן: `http://localhost:8787/image-choices.html`.

הבחירות נשמרות בדפדפן וניתן להוריד אותן כ־CSV. הדף אינו מוריד או מחליף את תמונות המטע.
